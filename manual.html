Como Atualizar Seu Site

Este guia foi criado para ajudar os responsáveis pela ONG Semear o Futuro a realizarem pequenas atualizações no site, como mudar textos, telefones ou fotos, sem precisar de conhecimentos avançados em programação.

1. Como abrir os arquivos

Para editar o site, você não precisa de programas caros. Basta usar o Bloco de Notas do Windows ou um editor gratuito como o VS Code.

  1. Clique com o botão direito no arquivo index.html.
  2. Escolha "Abrir com" > "Bloco de Notas".
  3. Você verá vários códigos. Não se assuste! Procure pelos textos que estão na cor preta (no bloco de notas) ou branca (nos editores).

2. Alterando Textos

Todo o conteúdo de texto do site está dentro de "tags". Por exemplo, um parágrafo fica dentro de <p> e </p>.

Para mudar a frase de boas-vindas:

<h2>Transformando Vidas Pela Educação</h2>

Apague apenas o texto destacado e escreva o novo. Não apague os símbolos < e >.

3. Alterando Links (Whatsapp, Facebook)

Os links ficam dentro da tag <a href="...">. O endereço do link fica dentro das aspas.

<a href="https://facebook.com/ongsemear">Facebook</a>

Basta trocar o endereço dentro das aspas pelo novo link.

4. Atualizando os Números de Impacto

Para atualizar os números da seção "Nosso Impacto", procure por este código no final do arquivo index.html:

<span class="stat-number" data-target="150">0</span>

Mude o número 150 para o novo valor desejado. O site fará a animação automaticamente.

5. Trocando Imagens

Para trocar a imagem de fundo ou fotos dos projetos:

  1. Salve a nova foto na pasta do site.
  2. No código, procure por <img src="..."> ou no arquivo style.css (para o fundo).
  3. Substitua o nome do arquivo antigo pelo novo.
Dica: Tente usar imagens leves para não deixar o site lento!

Precisa de mais ajuda? Entre em contato com o desenvolvedor voluntário ou consulte tutoriais básicos de HTML na internet.
